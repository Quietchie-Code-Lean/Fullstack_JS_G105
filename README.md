# Fullstack_JS_G105

This repository serves as a **Learning Roadmap** for my journey through the Fullstack JavaScript career path.  
It is designed to document, organize, and showcase all the projects, exercises, and notes developed during each stage of the program.

The repo is structured by units and topics, making it easier to track my progress and revisit concepts whenever needed.  
Each folder corresponds to a specific subject (e.g., HTML5, CSS3, Flexbox, Bootstrap, Git & GitHub, GitHub Pages, etc.), and inside those folders, you will find the related projects and practice exercises.

The main goals of this repository are:
- 📚 To keep a well-documented record of my learning process.  
- 💻 To showcase the projects I build throughout the course.  
- 🚀 To use it as a reference and portfolio of my Fullstack development skills.  

This repo represents not only the code I write, but also the path I’m following to become a **Fullstack JavaScript Developer**.
